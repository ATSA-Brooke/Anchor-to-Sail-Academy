QUICK GODADDY SETUP
1. Sign in to GoDaddy.
2. Open your domain anchortosailacademy.com.
3. If you purchased GoDaddy Web Hosting/cPanel, open File Manager and upload the contents of this folder into public_html.
4. Make sure index.html is directly inside public_html, with styles.css beside it and the images folder intact.
5. If the domain is not already connected to that hosting account, use GoDaddy's domain/hosting connection option or update DNS to point to the hosting plan.
6. Your email address brooke@anchortosailacademy.com is already used in the site's contact buttons; no password or mail settings are placed in the website.

If you are using GoDaddy Websites + Marketing instead of Web Hosting/cPanel, this custom HTML site cannot simply be uploaded as the full site. In that case, use a GoDaddy hosting plan that supports file uploads, or host the site elsewhere and point the domain to it.
